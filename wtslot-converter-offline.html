    Loading them on the M

    1. Copy the wtslotNN.wav files to the root of the M's SD card.
    2. On the M, set UWT Slot to the file's number and Skip to 1.
    3. In the SD Card utility, run Import 16bit User WT (from SD). Repeat for each slot.

    Check the slot number first. On firmware 1.11, importing a slot with no matching file on the card freezes the M until you power-cycle it.

    What the converter does

    It splits the file into frames, picks 64 evenly spaced positions across them (blending neighbouring frames, so short tables are interpolated and long ones thinned), and resamples each wave to 256 samples, keeping harmonics 1–127. It removes DC and normalizes the whole table to −0.3 dBFS, so the waves keep their levels relative to each other.

    The M reads the file blindly from byte 44, so the output always uses a plain 44-byte WAV header.
